# Open WebUI

Open WebUI provides a friendly chat interface for local large language models.

- Primary image: `ghcr.io/open-webui/open-webui:main`
- Dependency image: `ollama/ollama` for model serving on port 11434
- FlyPC maps each user to dedicated host ports for the UI and Ollama API

This catalog entry is listed in Apex only. Install when you want a personal Open WebUI + Ollama stack.
