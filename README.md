# FlyPC

Personal computing on the fly.

FlyPC is a web-based operating system designed for secure, portable, and flexible computing. It enables applications to run in isolated container pods, providing a safe and scalable environment for modern digital work.

## Overview

FlyPC brings together the best of both worlds:
- Secure applications running in containerized pods
- Native applications delivered through streaming
- Web-native applications available as browser-based pages
- App-specific storage mounts without granting broad file access

## Vision

FlyPC aims to make computing more secure, portable, and accessible by combining container-based application isolation with a browser-first operating environment.

## Ideology
 - Open Source: We prefer open source tools and libraries and encourage community contributions.
 - Ethical Data Use: We only use public data and software in ways that respect originator intent and licensing.
 - Privacy First: User data is private by default; minimal data is collected and only with clear consent.
 - No Activity Monitoring: FlyPC does not support covert user activity monitoring or telemetry that tracks individuals.
 - Transparency: System behaviors, defaults, and security promises are documented and auditable.
 - User Control: Users decide what gets shared, stored, or mounted; defaults favor user autonomy.

## Key Features

 - Secure apps running in isolated container pods (sandboxed per app).
 - Support for streamed native applications (interactive streaming from trusted hosts).
 - Web-native apps served as ordinary web pages for fast, lightweight use.
 - Per-app storage mounts with scoped access — apps cannot access your general filesystem unless explicitly granted.
 - Cloud-friendly and device-agnostic: carry your workspace across devices via the browser.
